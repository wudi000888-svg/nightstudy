# 0.9：考试词书、成品音频与雨夜体验

2026-10-16，依据本轮用户明确的实施要求。保留已评审的移动 H5 应用壳与首页四区，继续使用 Fastify / Node 24、PostgreSQL、React 19 / Vite 和现有 FSRS 库；不因技术栈名称而重写已经验证的学习身份、幂等与复习算法。

## 方案与边界

- 标准考试目标包括雅思、托福、大学四级、大学六级、专四、专八，并补充考研、GRE。用户已澄清“8级”即专八、“专6”为口误，不创建虚构考试分类。词书由固定的开源词表生成，复用规范 Word；源文件、加工许可、版本与未准入清单见 `OPEN_CONTENT_REUSE.md`。
- 音频按用户最新指令采用“真人录音优先，缺音单词与例句由 Codex 在本机离线生成，再校验打包”。口音、来源和生成方式保留在数据记录及维护文档，普通学习页面只提供美式/英式播放。不在 VPS 即时合成、不调用浏览器语音、不因找不到录音就切换成别的口音；离线生成失败仍留空。
- 例句使用规范化英文全文的 SHA-256 关联音频，保留大小写以免缩写和专名混淆。不同站点仍各自拥有音频元数据；没有对应条目时返回空音频列表。句库、学习词卡、悬浮词卡与学堂共用成品播放器，换词、换页、切后台和录音都会终止旧音频。
- 雨夜背景由原创 CSS 构建，管理员可上传静态壁纸并设置焦点、遮罩和动态许可。上传只接受 JPG/PNG/WebP，在服务端验证、去元数据、限制像素和尺寸后转换为 WebP；不接受任意远程地址。公开配置与图片属于本站公共外观，用户与账户数据不在其中。

## 性能措施

动效仅使用两层合成动画，不使用逐帧 React 状态或每滴雨的 DOM；覆盖首页、后台、减少动态、省流与慢连接时关闭。管理与学习页面继续按需加载，不把整套后台放进首页。JS/CSS 在构建时预先生成 Brotli/gzip，Fastify 优先直接发送固定压缩文件，减少移动网络传输与 VPS 实时压缩负担。壁纸只有一个当前版本，通过内容 SHA 地址及 ETag 缓存。

线上容器只需解包成品音频的 Python，不安装语音引擎、声线模型或 GPU 推理环境。生成与编码的 CPU 成本由本机构建承担。词书安装复用已有字典，不再次导入77万词典、释义或用户学习记录。缺词、缺音、词书条数与真人/合成比例按真实产物报告，不将预测或社区词表说成完整官方考试大纲。

## 验收与发布记录

### 已完成的浏览器与性能检查

最终 0.9 前端构建在一次性账户、独立数据库和外置表空间上完成真实 HTTP 与浏览器验收，未借用生产账户。390×844、320×568、844×390 均无正文或横向溢出，首页最小触控按钮46×46像素。管理员预览、上传、焦点与遮罩保存后刷新保留；英文词音及句音的英美四路均实际播放，切入口保持单播放器，关闭模块立即停止。四路 `Range: bytes=0-31` 均返回206，媒体体逐字节匹配本机成品。

最终入口JS原始278,325字节，Brotli传输81,168字节，减少70.84%；这是单个入口文件的传输量，不是全部资源、首屏时间或并发容量。真实浏览器的已激活 Service Worker 缓存了正确解码的278,325字节，SHA-256与磁盘一致。`/site`与`/me`实际同时发出，开始相差0.655毫秒；模拟1,200毫秒网络延迟时，账户确认前只显示启动等待，没有提前渲染Home或个人页。

本机另使用真实隔离PostgreSQL、40词/200书词关系/5本词书的小型夹具，对书架、前缀查询、精确查词进行了并发1/10/25的675次 `app.inject` 请求，全部200。并发25时三项p95分别约27.49/67.03/46.03毫秒。这些结果不含TCP/TLS、真实用户规模、鉴权评分写入或VPS网络，且当时有离线音频任务运行，不能据此承诺线上RPS或最大用户数。

独立QA进程、库、外置表空间、音频副本、凭据和浏览器测试状态均已精确清理；原native5198进程与业务数据未参与写入。桌面浏览器尺寸模拟不等同实体iPhone/Android验收。

### 音频成品、最终回归与部署

冻结的业务实现已通过82个文件、695项测试，包含真实双PostgreSQL站点隔离、音频导入幂等及来源元数据更新、文件防篡改与LRU、HTTP范围请求、播放器迟到事件与生命周期、壁纸鉴权和并发版本冲突。没有跳过数据库集成测试。另有7文件33项词书/词组/双语专项检查通过。随后补充句音ContentPack的无变化重复导入判断，相关6项真实PostgreSQL安装回归与工具类型检查再次通过；这6项包含于前述测试集合，不重复累计。

本机既有站点缺少词组与双语基线，故先做独立恢复演练：从运行中的源库只读制作142,420,587字节逻辑备份，核对目录后仅恢复到全新随机命名、绑定OID的外置表空间克隆。克隆实际安装后，44张业务表及14条迁移记录的保护散列、全部明确例外逐行核验通过：579个文本空字段填补、13条新释义、9,223条例句、483条词组关系、2本词组书及437条成员关系。两条与先装词组包重合的非空英文释义原样保留并计入冲突。原有非空文本、账户、学习记录及770,611条Word全部保持，源服务未停止、源库未写入；这次演练没有把备份恢复到业务数据库。

最终内容安装又从同一份已验证备份恢复到另一个全新随机克隆，实际应用第15条迁移并安装两份缺失基线与11本考试词书。新克隆保留770,611个Word和全部18,775个学习目标；新增13本词书、48,599条成员关系，原44张业务表的保护范围及明确内容例外均逐项验证。18本默认词书与克隆保留的其他原有词书分别统计，未覆盖或删除用户的词书。此阶段没有导入音频，也没有启动网页、后台任务或改写源数据库。
