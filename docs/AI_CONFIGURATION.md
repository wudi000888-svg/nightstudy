# 可选 DeepSeek 配置

NightStudy 的词书学习、服务器 FSRS、双语内容安装和英美音源不需要 DeepSeek。0.6 后台提供可选的 DeepSeek 密钥设置、手动连接测试和单词内容预览；**默认未配置，不自动请求、不自动补词，也不自动收费**。

## 管理员操作

仅本站管理员可以配置。后台选择当前代码支持的 `deepseek-flash` 或 `deepseek-v4-pro`，输入自己的 API key 并启用。地址固定为 `https://api.deepseek.com`，不能填写任意代理地址。保存配置不调用上游；删除密钥同时禁用功能。

“测试连接”发送一条有界的 JSON 检查请求。“预览缺失内容”只针对一个已发布词条，发送该词的公开词头、词性、原释义与待补字段；它不把账户信息、私有词书或学习记录作为提示内容。已有双语内容不重新生成，没有缺项时直接返回空候选。

管理员主动测试或预览会使用其 DeepSeek 账户额度，费用由该账户承担。请先自行查看服务商的计费和账户余额。这里不承诺免费额度、固定单价或指定模型持续可用；限流、余额不足、无效密钥、超时和无效结果会明确失败，不自动重试。

## 候选与写入边界

预览绑定同词的原 `Sense`、源语言、精确原文 SHA-256 和目标空字段。生成例句要求完整原词及两种语言，并保留 `provider`、所选模型、生成时间与 `review: pending`；所选模型名不证明服务商响应背后的具体权重版本。

所有成功预览返回 `applied: false`。当前没有自动批处理或候选应用接口；候选不写入 `Word`、`Sense`、`WordExample` 或学习记录，不能把“预览通过”说成“词条已经补齐”。结构检查也不证明含义和译文正确。内容、配置或管理员权限在请求期间变化时，返回的候选会被丢弃。

管理员如需采用内容，须自行逐项校对，走已有内容编辑流程。站点编辑按本站来源记录，不自动成为可公开分发的词库贡献，也不把上游输出冒称 NightStudy 的 MIT 原创例句。

## 密钥与运行限制

每站密钥以 AES-256-GCM 加密存入该站数据库，密钥材料由本站认证 secret 派生，并绑定站点及安装实例身份。读取接口只返回“已配置”状态和末四位遮罩，不回传原密钥。备份需保管对应数据库、实例身份与认证 secret；轮换认证 secret 后若无法解密，须重新配置 DeepSeek key，不能依赖数据库密文恢复明文。

服务器单次请求限制 20 秒和 64 KiB 响应；连接测试最多 32 个输出 tokens，缺项预览最多 2,400 个。数据库限流为每站每分钟 20 次、每管理员每分钟 6 次；请求 lease 限制每站同时 2 次、同管理员同时 1 次。它们是资源边界，不是服务可用或吞吐保证。

后台契约如下，路径均位于本站 `/api/v2` 下：

| 方法与路径                        | 用途                                             |
| --------------------------------- | ------------------------------------------------ |
| `GET /admin/ai/deepseek`          | 读取启用状态、模型、是否配 key 和遮罩            |
| `PUT /admin/ai/deepseek`          | 保存 `enabled`、`model`、`apiKey` 或 `removeKey` |
| `POST /admin/ai/deepseek/test`    | JSON `{}`，主动连接检查                          |
| `POST /admin/ai/deepseek/preview` | `{wordId}`，只读候选及上游 usage                 |

当前回归使用隔离 PostgreSQL 与受控上游响应验证鉴权、加密、限流、源变更和不写内容的边界。没有真实 key 的付费上游调用结果，不将这些测试声称为 DeepSeek 在线可用性或语义质量验收。
