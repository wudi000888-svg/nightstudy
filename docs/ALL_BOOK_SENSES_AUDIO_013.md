## 内容范围

18 本内置词书共 18,767 个有效词目、69,840 条成员关系。新的学习内容为 49,992 个原子义项和 99,984 条中英双语语境例句；每个义项标明词性、成对释义及独立语境。不同词或义项使用同一句英文时保留全部明确引用，不能将词级候选例句自动借给另一个意思。

## 发布与验收顺序

1. 全部生成分片完成；原 WAV/MP3 检查和 MP3-only 安装包解包通过。
2. 每个原安装包由独立 Node 工具核对；涉及旧音复用的 16 个片段包另作明确分区和独立复核。
3. 全局核对所有 95 个文字叶、101 个媒体包、当前完整引用、79 个暂缓键和完整纠音记录，生成九字段的严格 collection 与固定子包清单。
4. 媒体从草稿转为独立、非 latest 的资源发行；公开下载按固定字节数和 SHA 检查。之后应用执行完整 Compose 冷安装、独立数据库检查、18 本书的 HTTP 与 H5 内容/音频验收。
5. 全部通过后发布应用源码及容器。GitHub 发行并不自动代表 Native 或 VPS 已部署。

已有公开音包与内容包保持不可变。新媒体不放进 Git 或应用镜像；安装按固定清单下载和校验。安装缓存、解包媒体、数据库、WAL、备份及升级暂存需要分别计入磁盘预算，实际字节数以最终公开清单为准。

本轮单包集成曾发现 GitHub 草稿按标签 REST 查询返回 404，以及 `gh --slurp` 与 `--jq` 不可共用。修复均限于传输/查询入口，失败日志保留，没有修改媒体检查阈值或重新合成既有成功分片。

首次全量打包在前 42 包通过后，因第 43 包的 GitHub 只读下载返回 HTTP 502 而停止，尚未进入全局检查。下载层随后增加三次上限的临时 HTTP 重试；成功传输后的摘要或字节错误仍立即失败，上传和校验命令不重试。下载使用独立临时文件，验证后原子创建目标，既有文件不会覆盖。五项模拟边界与原检查已在 [云端工具检查 39263164343](https://github.com/wudi000888-svg/nightstudy/actions/runs/39263164343) 通过；已接受的媒体及其证据保持原摘要，生成任务没有重跑。
