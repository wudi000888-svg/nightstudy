# 全词书内容的有界安装与验证

2026-10-19 实施记录。当前线上和公开发行版仍是 `0.12.0-alpha.1`；本次源码检查通过不表示新增内容或音频已经发布、导入或部署。

## 安装流程

`senses:prepare` 先逐片验证集合、全局标识、词目并集、来源补充与全部文件摘要，仅保存文件身份和清单。大集合禁止走旧的整库解码接口。安装在一个站点绑定、带事务级锁的数据库事务内逐片读取；提交前再次检查全部输入身份。后片失败或已读文件中途变化都会回滚。

独立检查器使用同样有界的逐片读取方式，完整数据库验证保持一个只读快照。音频核验仅解析当前音频包请求的词义引用；未知词号走逐片全扫描，不静默漏验。全部暂缓键仍需在任何媒体安装前检查。

## 已完成验证

- 18 本词书的辨义矩阵已独立汇总通过：1,139 片、18,767 个不同词、49,992 个不同义项；226,112 个跨书目标共 678,336 次抽测。739 个目标在三次抽测中均无可用题，保留回忆学习回退。抽测不保证未来所有随机排列，也不代表词义穷尽或专家认证。
- 实际 95 片、18,767 词、49,992 义、99,984 例句的安装预检与独立检查器预检均通过；另验证首尾片音频引用。未连接数据库。
- 18 项安装器单元测试、44 项词义检查器自检、41 项读音策略自检、181 项音频检查器自检及限定工具类型检查通过。数据库原子性、站点绑定、重放与迟到文件变化回归继续由完整 CI 验证。

整库 Vitest 预检及第一次独立安装预检分别触发 384 MiB 任务进程树上限，均被保护器停止，swap 未增加。随后将 JavaScript 预算从 128 MiB 收紧为 96 MiB，并限制 young generation 为 2 MiB；在原 384 MiB 进程树、90 秒和健康门槛内，独立安装预检 16.42 秒通过，采样峰值 257.59 MiB；独立验证预检 2.11 秒通过。短任务的采样值不能当作真实零内存或整机稳定保证。

## 尚未完成

70 包新的逐语境读音人工决策已写完，仍需严格适配、旧策略证据交集和媒体校验。公开候选文本已按 95 片生成；其与冻结证明的逐字段复核发现原 35 词的 `sourceBindings` 差异，正在定位，未放宽语义比较或修改旧固定包。89,880 条已完成清单记录包含重复和未批准候选，不能当作可复用音频数。

新内容包、最终纠音及暂缓策略、全部缺口音频、整库数据库安装和 H5 验收完成后才发布新版本。本机继续单队列、小批次、原资源保护；不调用付费内容接口，不下载模型，不重启旧八 worker 音频构建。
