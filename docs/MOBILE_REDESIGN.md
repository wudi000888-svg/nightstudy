# 移动端学习体验

0.7 采用移动端优先的页面结构。学习首页保留原创雨夜场景，正文默认浅色青绿，个人偏好支持夜读与跟随系统。桌面使用居中的简洁布局，管理功能拥有独立入口。

## 页面与操作

| 入口     | 实际功能                                                         |
| -------- | ---------------------------------------------------------------- |
| 学习     | 当前词书、每日总词数、新学与复习、可展开的计划和30天学习记录     |
| 专注背词 | 固定学习组、回忆揭晓、四档真实评价、可选拼写、暂停和继续         |
| 内容     | 正在学、最近30天、全部已学、生词本、熟词本、句库、笔记及学习工具 |
| 学堂     | 原创短文、跟读、词汇听辨、专题练习及本人练习记录                 |
| 我的     | 计划、记忆曲线、口音、自动发音、拼写、字号、主题和站内提醒       |

专注页隐藏全局导航，操作栏位于底部，内容区域独立滚动。拼写使用正常表单提交，适配手机可视视口；页面与卡片支持减少动态效果的系统设置。返回任务页不会丢失服务器保存的进度。

释义与语境分开浏览：单词级例句不冒充当前义项的已核对例句。英文支持桌面悬停、触屏点击及键盘打开词卡；词卡内的文字不继续触发另一张卡。美式与英式发音各有一个按钮，星星和固定按钮有可访问的名称及即时提示。

## 真实保存与计分边界

- 句库只收藏本站当前可用的双语原句，服务端记录源身份和快照。状态查询按当前内容核对，不受收藏列表分页影响；来源内容更新后，旧收藏保持原文。
- 笔记归本人所有，支持搜索、编辑、关联词条与移除；版本冲突要求重新读取，不覆盖另一处已保存的编辑。
- 学堂听辨使用服务器核对过的本站音源，按固定题目快照在服务器判分。音源缺失时不能开始听辨，不用空音频假装已就绪。
- 短文、跟读与专题保存完成记录，不伪造语言能力得分。跟读录音只在当前设备临时保留，可回放；最长60秒、最多8 MiB，不上传、不做发音打分，离开后释放。
- 句子收藏、笔记、学堂完成及听辨得分不会写入 FSRS 复习证据，也不增加每日已练习词数。

每日目标继续按复习与新学的不同词总数计算，复习优先。每组创建时固定拼写开关，之后更改偏好只作用于新组；未安排拼写的组不会生成虚假的拼写完成记录。新版本的数据契约以当前结构为准，不承诺对早期版本的数据格式进行适配。

## 偏好与提醒

登录后的偏好保存在当前站点的本人账户，换设备重新读取。访客仅在当前浏览器保存主题、口音和字号。账号和站点切换会隔离偏好、收藏与内容缓存，迟到的请求不能更新新账户页面。

自动发音需主动启用，并受浏览器音频策略限制；播放失败会提示，不静默换成设备语音。站内提醒只在页面打开且可见时按设备当地时间显示，不发送离线系统推送。学习日仍按计划时区凌晨04:00切换。

## 部署与范围

沿用 Docker Compose、独立站点认证与数据库、群站配对及后台更新检测。新增四张表用于偏好、句子、笔记与学堂记录，通过 `pnpm db:deploy` 安装。应用代码不需要本地大语言模型，AI 服务仍由管理员自选配置；本轮改造不调用真实付费供应商。

学堂首版为六节原创示范课程，后续可以扩充内容；不宣称已经包含完整课程体系、语音识别评分、离线推送或实测高并发容量。完整词典收录范围和双语内容覆盖范围继续见 [内容包](CONTENT.md) 与 [双语内容](BILINGUAL_CONTENT.md)。

## 本机验证

62 份测试文件、563 项测试全部通过，包含双 PostgreSQL Realm、学习组幂等、拼写偏好快照、句子精确收藏状态、笔记冲突及听辨评分。类型检查、格式检查与外置生产构建通过。

隔离浏览器在390×844完成三词回忆、三次拼写、3/3每日去重进度；390×480检查回车提交和底部继续按钮。之后按真实到期时间从首页一键进入复习，关闭拼写的新组评价后直接完成。偏好刷新保持、句子实际入库、笔记保存、短文完成和听辨1/4答对显示25%均通过，统计仍为3个已学词与1次真实复习。跟读未访问真实麦克风，模型调用为0；这些检查不代替实体手机键盘或语义准确率评估。
