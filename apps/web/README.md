# NightStudy Web alpha

React + TypeScript + Vite 源码前端。原创SVG窗边场景和独立CSS构建雨夜、玻璃面板、琥珀操作的视觉；没有复制旧bundle，也不依赖未知许可照片。

业务数据全部来自同源 `/api/v2`，认证通过 `/api/auth` 的真实Cookie会话。根服务在HTML模块加载前注入 `window.__NIGHTSTUDY_CONFIG__={basePath}`；Router、API与认证使用同一个base。Vite生产构建采用相对资源URL，服务端负责按挂载前缀提供HTML资源路径。开发服务代理至127.0.0.1:5198。

当前页面包含词书/计划、服务器学习组与四档评分、组末拼写、到期复习、词典/生词本、网页翻译、熟词批次预览确认撤销与导出、目标基线和推荐计划、真实FSRS点的SVG曲线、账号/设置、首管理员初始化、基本后台。

词典搜索使用服务器前缀匹配和游标分页，选词后单独读取完整释义。数据包覆盖数量来自安装元数据，不作为去重后的词库总数。音标按来源展示：未分型的词库读音标注不称完整英美IPA，服务器提供独立英美字段时才展示对应内容。设备发音选择实际可用的en-US/en-GB语音，并以播放开始、结束和错误事件更新状态。

网页翻译接入本站配置的Google网页兼容服务，展示真实返回结果及非官方服务标识；未配置、上游失败或超时时提供Google官方网页入口，不嵌入Google网页。词书后台词条和候选成员按页搜索，不向浏览器下载全词库。

内置原创演示词书保留演示标识，真实内容按词条来源与许可展示。无状态的个人记忆显示空态，曲线不使用随机或手绘默认数据；词间分布不称准确率置信区间。

Alpha边界：词书后台提供新建、元数据/状态编辑与词条编辑；复杂词书发布、完整账户注销/全部历史导出、单词级曲线筛选和全面离线持续学习尚未包含。已实现网络写入持久重试，队列按本站用户隔离，服务器处理幂等与revision。数据包安装及翻译网关配置由仓库根流程管理，未提供的例句、词形或录音不补造。

运行、数据库、版本和依赖由仓库根脚本管理。请从根执行 `pnpm dev:web`、`pnpm --filter @nightstudy/web typecheck`、`pnpm --filter @nightstudy/web build`。
