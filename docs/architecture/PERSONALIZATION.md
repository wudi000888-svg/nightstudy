# 熟词证据、每日总量与个人记忆

本稿区分`0.5.0-alpha.1`当前实现规则与后续设计方向。它说明行为，不是本轮测试、发行或生产验收证明；结果以对应版本的[验证记录](../../README.md)为准。用户自报熟词、诊断测试、真实回忆评分和拼写练习分别记录，不互相伪装为复习成功或全词表掌握。

## 每天N个不同词

正式设置是dailyTotalGoal（1–100）：复习与新学的canonical wordId联合去重，不是每天额外增加N个新词。先给本站全部已学词中今日到期的复习预留预算，剩余才从当前词书选新词；本书只是新学来源。今日稍后到期的预留复习继续等待，不提前写评分；超过预算的逾期词独立显示。

选书流程为词书 → 计划预览 → 用户确认 → 今日任务。只读preview给出复习、新学、已完成、保留预约与未安排逾期；原子confirm同时更新书、总目标、组大小和计划，并核对settingsRevision。预览不是任务签发，实际确认使用当时的服务端进度。

| 展示                | 当前含义                                                                |
| ------------------- | ----------------------------------------------------------------------- |
| 已评价的不同词      | 当日已接受真实评分的wordId；不是掌握证明，也不等于拼写全部完成          |
| 计划复习 / 计划新学 | 真实当日安排，含保留的已签发承诺；中途降低目标不会强行回收旧组          |
| 待巩固              | 今日已评分且FSRS学习/重学状态在本学习日还会到期的不同词；未到期继续等待 |
| 待拼写              | 已评分、固定任务尚未完成拼写的不同词；跨书重复项去重                    |
| 未安排逾期          | 超出当前计划或尚未被安排的逾期词，仍保留，可主动额外复习                |
| 等待同步            | 本地待接受操作，不计入服务端已评价词数                                  |

同一个词的当日短期巩固是到达真实FSRS dueAt后再回忆、再评分，产生真实ReviewLog；当天的不同词总数仍只计一次。拼写只记录练习结果，不重复写FSRS。主动额外复习的真实评分也计入当天不同词数，允许超过主目标，不增加新学额度。

## 04:00学习日与任务承诺

每日计划固定timeZone、localDate、startsAt、endsAt：当地04:00到下一次04:00，按左闭右开窗口计数。夏令时日期可能不是24小时，不用设备时区或简单减24小时重新解释历史窗口。

时区更改以pendingTimeZone/timeZoneEffectiveAt预约到当前学习日结束后应用，不切碎当日数据；新窗口不与旧窗口重叠。任务保留签发计划的日期与时区，日期显示使用该快照。无快照的legacy记录明确标注当前设备时区。

固定组保存wordId、内容快照、题目与itemId，会话和词进度都有revision；服务端确定本站当前用户，客户端不能通过提交siteId/userId转移任务。换书、改变总目标和跨日保留已签发组，不因为降低额度在评分阶段拒绝原组。昨日已经评分、只剩拼写的项不占新学习日词数，尚未评分项保留为可继续的任务承诺。

pause保留固定内容和未评分预约；任务页提供24小时延期，defer接口最多七天，暂停并延后词条选择，不修改原dueAt或已接受评分。resume清延期并恢复同一个任务；同类另一主组进行中时，先暂停或完成它。任务页列出进行中、暂停、延期与完成历史，换设备登录本站后读取同一任务，不在浏览器重新猜一组词。

## 同步与冲突

断网动作只暂存为待接受命令，不能显示为服务器完成。相同commandId重试幂等；服务端revision冲突保留最新评分，客户端不自动改写FSRS。

409冲突持久标记后，用户可先读取服务器最新任务，再明确确认“放弃这条未被服务器接受的本地操作，保留服务器已接受记录，随后重新读取任务”。仅删除当前scope内已标记冲突的这一条本地命令，其余队列保留。账号切换及异步同步使用scope校验，不将另一账号的暂存结果显示为当前账号的进度。

## 七天复习负担

七个学习日使用当前计划时区快照与当前持久dueAt。每列的当天到期dueUnique与此前逾期overdueCarry互不重叠，可相加为当日负担。假设后续尚未复习，不计未来新增学习，也不预测评分成功。

同一个词可能连续出现在多天结转中，不能把七列相加当作不同词总数。真实评分、时区生效、内容或暂停状态变化都会使下一次读取结果改变。该图与“不再复习”的FSRS记忆保留率预测分开，不把待办数当作客观准确率。

## 熟词声明与诊断建议

熟词导入生成本人已确认claim，不创建词条或伪造ReviewLog。支持text/CSV/JSON预览、确认、撤销和导出；已有真实学习历史继续保留。跨站交换文件重新匹配本站词条，不迁移账户、认证、FSRS或考试结论。导出分批完整，但不是跨批次事务快照。精确格式和限制见[API](../API.md#熟词声明测试与个人统计)。

自报熟词降低额外新学曝光并保留抽查，不能因为一次导入将dueAt推到数年后。目标诊断按已安装范围和难度分层抽样，认知与拼写分开；完整内容的报告标limited_sample，只确认实际抽样范围，不输出标准化考试总分或未经验证的英语等级。

新诊断建议提供dailyTotalGoal、newWordSuggestion、reviewPressure、groupSize与countBasis=daily-unique-words。总量建议和新学建议分开，用户显式采用才改设置，确认时仍按当日真实安排计算。历史report.suggestedPlan.dailyNewLimit仅是当时的新学建议，不自动转换成每日总量；Settings中的同名兼容字段则镜像总目标，二者不能混用。

## 个人记忆与后续方向

个人曲线基于本人真实评分后保存的FSRS状态和dueAt，无记录时保持空态；模型预测、实际自报回忆与客观拼写分别解释。词间分布带不是个人准确率保证或置信区间，聚合数据限额在响应中说明。现有[每日任务](../DAILY_TASKS.md)、[API](../API.md)是实现契约。

历史设计中的大规模初测、额外语境/音频题、分散时点长期稳固判断、异步曲线缓存、模型参数重建与更复杂证据融合仍是独立后续方向，不能把当前有限抽样包装为已经实现全部方案。调度采用独立FSRS实现，不声称得到其他学习产品的内部模型。
