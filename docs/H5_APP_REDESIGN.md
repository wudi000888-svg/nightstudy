# NightStudy H5 应用改造设计

设计日期：2026-10-15。用户于 2026-10-16 批准全量施工；0.8 已实施、发布并部署，本稿保留实施契约及实际验证记录。

本轮以用户提供视频约 2 秒处的首页为布局参考，转向真正的移动 H5 应用体验。首页采用一个完整屏幕的固定构图，功能以覆盖页和独立学习流程展开。当前页面式导航、长首页和常驻文字导航可以直接替换。

用户已允许全部不兼容改动，不要求兼容旧数据库、旧接口、旧路由或旧客户端缓存。配套 HTML 原型中的日期、连学天数、词数、学习进度和曲线仍是设计示例；实施版必须使用当前账户的服务器记录，不能将原型数据写入用户进度。

## 1. 首页：四区固定构图

首页是整个应用的唯一根屏。进入应用先看到完整壁纸与安静留白，不是一个需要向下浏览的内容门户。参考视频的位置关系、层级和转场节奏；品牌、壁纸和图标使用本项目自有或已获授权的素材。

| 固定区              | 构图和内容                                               | 操作                                                            |
| ------------------- | -------------------------------------------------------- | --------------------------------------------------------------- |
| 左上头像            | 头像单独悬于壁纸，不增加网站横幅、导航标题或用户名长行   | 点击进入个人中心覆盖页                                          |
| 偏上签到块          | 仅显示签到与日期，作为视觉锚点，周围保持留白             | 点击打开日历与学习记录；完成条件由真实学习记录决定              |
| 下部 Learn / Review | 两个并列的主要操作与待学词数，保留视频的大留白与靠下位置 | Learn 进入新学或继续对应任务，Review 进入到期复习或继续复习任务 |
| 底部三个纯图标      | 无持续文字标签，独立于 Learn / Review；位置随安全区适配  | 分别打开次级模块覆盖页，映射见下一节                            |

首页不再追加书架、工具九宫格、长篇计划、统计图、课程列表、公告或管理入口。详情收进二级覆盖页。背景铺满屏幕，壁纸裁切按主体保护处理；必要的明暗遮罩只用于保证文字可读，不给整个背景加模糊。

当前词书、词组和进度放在“我的学习”，不在首页额外增加一行。已登录且未选书时，Learn 打开选书与每日目标设置；未登录时先进入登录，成功后恢复刚才的意图。目标设置完成后回到首页，不把书架永久展开在首页上。

本稿建议将签到与总目标完成分开：服务器确认完成当天首个有效学习组后点亮学习日历；仅点击签到块、查看释义或尚未同步的动作不产生签到。完成全部每日计划才显示“今日完成”。这项规则是新方案的设计选择，不冒称视频已证明该算法。首页构图不因状态变化增加新的统计面板。

## 2. 三个纯图标：模块入口，不是常驻 Tab

以下映射是本稿的设计建议；视频可直接确认的是三个纯图标的布局和覆盖页交互，不能将视频未说明的业务含义当作事实。

| 图标建议       | 模块     | 覆盖页内容                                         |
| -------------- | -------- | -------------------------------------------------- |
| 学堂图标       | 学堂     | 阅读、跟读、听辨、主题练习与练习记录               |
| 卡片或书签图标 | 我的内容 | 生词本、熟词本、句库、笔记、词组本和自定义词书     |
| 趋势或日历图标 | 我的学习 | 今日任务、当前词书与计划、学习日历、记忆曲线和统计 |

点击图标后，模块以完整覆盖页展开，首页仍是下层根屏，但背景动画暂停。覆盖页顶部有明确的向下关闭按钮，关闭后回到同一个首页。覆盖页内不继续显示这排三个图标，不形成“学习／内容／我的”常驻底栏。

每个模块保存自己的列表位置、筛选和二级页面栈。关闭学堂再打开，回到刚才课程位置；关闭我的内容再打开，保留刚才的分类与滚动。模块记忆受当前站点和账户约束，退出登录、切换账户或站点身份改变时清空。

纯图标都具备辅助技术可读名称；桌面悬停显示功能名。首次使用可以在简短引导中解释三个入口，日常界面保持纯图标。个人中心只从左上头像进入，管理入口放在管理员自己的个人中心内。

## 3. 学习流程：独立沉浸屏

Learn 和 Review 进入独立的 StudyFlow。它覆盖首页与模块，不携带任何全局导航；内容和底部动作形成稳定的单屏操作节奏。

| 区域     | 行为                                                                     |
| -------- | ------------------------------------------------------------------------ |
| 顶部     | 返回、真实组进度及少量学习工具；星星与固定按钮提供功能名称和真实保存反馈 |
| 中央词卡 | 单词或词组、词性、英美音标和对应喇叭；揭晓后展示中英对照释义、例句和搭配 |
| 内容区   | 长释义与例句在内容区内滚动，切换义项和例句不挤走底部主动作               |
| 底部     | 根据阶段呈现揭晓、回忆评价、拼写提交或下一词；按钮位置稳定，适合拇指触达 |

美式和英式各有一个播放入口，喇叭位于对应音标之前。面向学习者只显示口音与播放状态，不展示技术备用线路、音源实现、供应商或接口信息。

英文词可打开详细词卡；中文不触发。桌面使用悬停，触屏使用点击；词卡内的释义与例句不再二次弹卡。词卡内可播放英美发音、查看词性和双语内容。已在生词本中的词显示已收藏状态及适当的移除操作，不能再次显示“加入生词本”。

星星的含义统一为生词收藏，固定图标仅表示保持当前查词卡，不影响熟练度。生词自动移出与自动进入熟词本仍依据实际复习证据，不能用收藏、看过或播放次数代替。卡片切换动画与网络确认分开处理，按钮点击后的动效不能冒充服务端已保存。

回忆主流程建议将底部保持为两个动作：“记错了”和“下一词”。后者在评价阶段明确表示“确认记得并继续”，对应正常记住；前者表示遗忘，回到短期巩固。需要精细评价时通过二级学习工具选困难或轻松。选释义、揭晓、查词、播放都不单独写入复习记录；只有服务端接受明确评价才推进任务。拼写提交单独进入对应阶段，不把“下一词”当作跳过必做拼写的入口。

## 4. 学习目标与状态契约

每日目标仍是“新学与复习的总词数”，先安排到期复习，再分配新词。同一词当天按唯一学习身份去重；重复巩固可能产生真实复习记录，但不重复占每日词数。词组按自己的规范学习条目管理。FSRS 决定实际复习时间，不能为凑首页进度提前制造到期或评分。

例如，原型目标为 50 词、到期复习为 32 词时，分配 32 复习和最多 18 新词；到期复习为 70 词时，分配 50 复习和 0 新词，其他到期项仍可在任务详情查看。这些数字仅用于解释分配规则。

| 状态               | 首页表现                                  | 点击后的行为                           |
| ------------------ | ----------------------------------------- | -------------------------------------- |
| 访客               | 保留完整构图，显示开始学习                | 登录后恢复原入口意图                   |
| 未选词书或未定目标 | Learn 为开始设置，Review 显示实际可用状态 | 选书、每日总词数、确认计划             |
| 今日未开始         | 新学和到期复习显示真实待学习量            | 原子创建一组任务，不因重复点击创建多组 |
| 有未完成任务       | 对应入口显示继续状态                      | 恢复同一个任务和当前词，不重建题目     |
| 暂停任务           | 保留继续入口                              | 恢复后回到原流程阶段                   |
| 无到期复习         | Review 保持位置，解释暂不需要复习         | 展示下一次安排或返回，不伪造空练习     |
| 新词额度为零       | Learn 告知今天先完成复习                  | 引导进入现有复习，不绕过每日总额度     |
| 今日目标达成       | 呈现完成态与真实完成反馈                  | 可以查看成果；额外练习必须明确选择     |
| 有短期巩固或待拼写 | 显示仍需完成的任务状态                    | 进入对应任务，不直接宣布整轮完成       |
| 弱网、待同步       | 小范围显示记录待同步，保留当前进度        | 同一操作重试，不重复评分               |
| 另一设备已推进     | 说明进度已更新                            | 读取服务器最新状态，核对后继续         |
| 已切换词书         | 按新书和今日剩余额度刷新任务              | 原未完成任务结束，旧链接只读           |

首页采用同一份聚合摘要读取当前计划、任务与入口状态，避免多个请求返回不同时刻的数字。服务器签发固定题目和稳定词项身份，返回当前阶段、版本与下一步；客户端不自行决定复习时间、熟练度、完成状态或账户归属。

2026-10-16 用户确认的切书规则优先：实际切换为另一词书时，结束原来所有未完成任务并释放未评分预约；保留 FSRS、复习记录和今日已练不同词数，再按剩余额度先复习、后安排新书新词。暂停、延期和待拼写的旧任务也结束。未被接受的离线操作保留明确冲突状态，不能静默丢弃或继续推进旧任务。只有降低目标或自然跨日时仍保留有效组。修复与验收见 [切书与任务修复](BOOK_SWITCH_TASKS_FIX.md)。

## 5. H5 应用壳与运行行为

### 屏幕、滚动与返回

应用以一个 Home 根屏、模块覆盖层、模块各自子栈、StudyFlow 和统一弹层管理器组成。URL 保留刷新、深链和恢复能力，但不再把每次屏幕变化都做成销毁前一页的网页跳转。

首页固定整屏，不产生正文长滚动。覆盖页与学习屏各自只有一个主要滚动容器；底部动作不随正文漂走。保留筛选、列表锚点与必要的编辑草稿，不无限保活全部 DOM、音频和课程内容。

返回优先级固定为：关闭最上层词卡或抽屉 → 返回模块内部上一层 → 下箭头关闭模块回 Home。学习屏的返回执行明确的离开行为，服务端已确认进度保留，待同步操作不能悄悄丢弃。个人中心关闭也回 Home。浏览器后退与系统侧滑遵循同一顺序；不做与 iOS 系统手势冲突的全屏自制返回手势。

直接打开课程或任务链接时，先确认站点和登录上下文，再恢复相应覆盖页或 StudyFlow。没有可用栈历史时，返回固定落在 Home，不跳到无关页面。重开应用从保存的位置恢复之前，要核对服务器任务版本。

### 安全区、软键盘和动效

统一的视口管理器处理浏览器工具栏变化、可见视口高度与偏移、刘海、底部手势区和横屏。头像、关闭按钮、主动作和底部图标都位于可触安全区；宽屏不把首页改造成网站导航，而是保持移动应用构图并适当限制内容宽度。

拼写使用正常表单与系统键盘。键盘展开时输入框和提交按钮始终可见，只移动需要移动的区域，不让整页重复跳动；键盘关闭后恢复原内容位置。需要分别验证 Safari 浏览器态、主屏幕安装态和 Android，不把桌面模拟视口当作实体机验收。

覆盖页展开、关闭和词卡切换使用短而连续的位移与透明度变化，首页和覆盖页不同时运行昂贵动画。支持系统减少动态效果；网络等待有真实加载或可重试状态，不靠延长转场掩盖失败。

### 音频与生命周期

全应用只允许一个发音播放器拥有播放权。换词、换口音或开始听辨时先终止旧播放；旧请求迟到不能重新播放上一词。播放状态包含加载、实际播放、停止、完成和失败，失败可直接重试。

自动发音仅在用户主动启用、浏览器允许且学习屏可见时执行。首次播放由真实手势启动；浏览器拒绝自动播放时保留明确的点击入口。切后台、关闭学习屏、切账户时停止自动播放并释放不再使用的媒体。录音继续需要显式点击与系统授权，不因页面恢复自动开启。

### 弱网、缓存和 PWA

首阶段目标是“弱网可暂存、刷新可恢复”，不承诺完整离线学习或离线登录。当前已签发任务可保留本机快照；提交使用持久化的同一操作编号重试。尚未被服务器接受的动作显示待同步，不计作跨设备已完成，也不能由客户端擅自重算 FSRS。

连续离线学习需要另行定义任务包有效期、事件顺序、跨设备冲突和评分归属，不能仅添加 Service Worker 就声称完成。后台同步能力仅作增强，恢复到前台和真实请求结果才是可靠确认依据。

PWA 包含安装名称、图标、启动方式和站点专属作用域。公开、带版本的静态资源与核对过的公共音频可以有限缓存；认证、管理页面、私人笔记、用户接口和 AI 密钥不进入通用缓存。首页离线壳与在线启动配置分开，不能长期复用带动态站点配置的旧 HTML。

有新版本时在安全位置提示更新，不在答题或保存中强制刷新。代码、接口与本机数据结构版本明确匹配；既然允许不兼容，可以清理旧缓存，但本次发布的待同步动作必须有明确处置，不能被静默抹除。

## 6. 多站点与后台边界

每份本机状态使用完整站点与账户身份隔离，至少覆盖来源域、挂载路径、实例身份、站点身份、用户身份和数据结构版本。退出登录或切换账户时，取消旧请求，卸载旧覆盖页和私有缓存；迟到响应不能填入新账户。

Service Worker 只处理本站挂载范围，根站 worker 明确绕过其他子路径站点。Cookie、API、静态资源、深链、安装入口和音频 URL 均遵循同一个挂载路径。重新部署导致实例身份变化时，不继续发送原实例的操作队列。

同域不同子路径可以兼容部署，但不当作浏览器级的强安全隔离；需要强隔离时使用独立域名。群站配对继续由管理员明确授权，前台用户不能通过 URL 或请求字段指定其他站点、数据库或账户。

后台继续拥有独立管理流程，保留词书导入、内容检查、用户管理、AI 配置、更新检测和群站配对。学习前台只呈现词典名称等有助学习的信息，不出现代码路径、许可清单、供应商协议、接口报错原文或部署术语；技术明细放管理界面和项目文档。

## 7. 分阶段施工顺序

本稿和配套原型已完成整体布局评审，以下阶段由本轮施工落实。

| 阶段         | 施工范围                                                 | 完成门槛                                         |
| ------------ | -------------------------------------------------------- | ------------------------------------------------ |
| 应用壳       | Home、四区构图、头像入口、三个模块覆盖页、返回与滚动模型 | 首页与视频关键构图对齐；覆盖页关闭与恢复行为一致 |
| 学习主链     | 选书定目标、首页摘要、开始与继续、沉浸词卡、回忆和拼写   | 真实任务从首页完成一轮；总词数和先复习规则正确   |
| 个人内容     | 生词、熟词、句库、笔记、词组与自定义词书                 | 收藏与列表状态一致；编辑、搜索、返回保留位置     |
| 可靠性与安装 | 音频统一、软键盘、弱网恢复、PWA、多站隔离                | 有真实网络异常和多站交叉验收，不只是静态截图     |
| 内容与上线   | 学堂、统计、后台回归、可用性、发布资料                   | 按本轮真实证据发布，不沿用旧版本验收结论         |

可以更换数据表、接口和路由，无需保留旧兼容层；具体技术栈迁移只在有明确收益时做。先建立最短学习闭环，再接回其他模块，不把视觉改版变成重写所有基础设施的前提。

## 8. 验收清单

- 首页在小屏、刘海屏和横屏保留四区关系，无网站头部、长书架或常驻文字底栏；三个模块关闭后回到原首页。
- 模块反复开关后仍保留各自滚动、筛选和子栈，退出登录后不显示上一账户信息；未提交内容有清晰处理方式。
- 深链刷新、站内返回、浏览器后退与 iOS 侧滑结果一致，不重复创建任务，不把返回做成首页永久拦截。
- 键盘展开、候选栏变化和收起时，输入框、主动作与上下文可见；需要实体 iPhone 和 Android 验收，当前未声称已通过。
- 连点开始、重复提交、成功响应丢失、断网重试、刷新和其他设备同时推进，均不重复计分、不重复分配每日名额。
- 每日总目标复习优先，重复词去重，短期巩固遵循真实到期时间；拼写、收藏和学堂完成不伪造复习证据。
- 英美音频各自准确对应按钮；切词后不播放旧词，前后台切换不意外发声；没有声音时不显示播放成功。
- 卡片英文可查、中文不触发、卡内不递归；收藏反馈与生词本一致，熟练度转移有真实记录。
- 根站与多个子路径站点分别验证登录退出、PWA 安装、缓存更新、音频和断网恢复，不共享私人状态。
