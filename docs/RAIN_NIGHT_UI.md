# 雨夜首页与自定义壁纸

2026-10-16，按本轮用户明确的雨夜氛围、动态与管理员自定义壁纸要求实施。保留已评审的 H5 四区单屏：左上头像、偏上签到、下部 Learn / Review、底部三个模块图标；不新增首页长内容或网站导航。

## 视觉方案

首页采用本项目原创 CSS 雨夜窗景：蓝灰夜空、雾月、远处楼窗和暖色微光、玻璃雨痕。窗景保留充足留白，签到块用沉静蓝灰，Learn 为暖象牙色，Review 为浅玉色。学习内容与覆盖页仍依照个人白天、夜读或跟随系统的主题，不将全文阅读区铺成动态背景。

仅两层平铺细雨执行 `transform` 动画，无逐滴 React 更新、canvas、每帧 JavaScript、背景位置动画或实时模糊。首页被覆盖、页面进入后台、系统要求减少动态、省流模式或 2G 时停止并卸载动态雨层，静态窗景保留。个人设置提供当前设备的动态雨景开关，按完整站点和账户 scope 隔离。

## 管理员自定义

管理后台新增“首页外观”，含静态手机构图预览、上传、水平与垂直焦点、深色遮罩、站点动态允许开关、保存及恢复原创窗景。仅接收 JPG、PNG、WebP，不支持外链输入；单图最多 4 MiB。服务端负责鉴权、内容验证、重编码与持久保存，前端只接受本站挂载路径内、带完整 SHA-256 的 WebP 图片地址。

公开读取 `/api/v2/appearance`；后台读取或更新 `/api/v2/admin/appearance`。配置包含 `mode`、`imageUrl`、`positionX`、`positionY`、`overlay`、`animationEnabled`、`revision`。焦点为 0–100，遮罩为 0–0.85；写请求带 `expectedRevision`，另一处修改后必须重新读取，不能覆盖新设置。图片上传与外观保存分步处理：上传成功后使用新的 revision 继续保存，第二步失败时可直接重试构图保存。

图片加载失败时恢复原创窗景；普通学习首页不显示技术错误。预览不启动雨动画、不制造学习进度。管理员更换的是本站公共首页图片，不向前台暴露文件位置或运维细节。

## 验证范围

自动测试核对动画许可策略、站点挂载路径和非法图片 URL 拒绝、上传大小与格式边界、生命周期监听清理以及后台上传后版本递进、冲突和迟到响应边界。构图、真实上传、320px 小屏、横屏和减少动态的浏览器验证结果以本轮实际验收记录为准，不等同实体设备与并发容量验证。

本机独立 Vite 预览已实际核对 390×844、320×568、844×390 游客首页：无正文滚动或横向溢出，全部首页按钮至少 44×44 像素；打开内容覆盖页立即移除雨层，关闭后可恢复。通过浏览器系统减少动态模拟核对，动态层为零。管理员上传流程已做处理器回归，实际鉴权上传与后端持久化的联调验收单独记录，不将静态预览当作上传完成。

独立随机 namespace、外置表空间与一次性管理员的完整服务已完成真实浏览器上传：原创 PNG 经服务端编码成 SHA-256 寻址的 WebP，焦点设为水平 100%、垂直 0%，保存后首页立即应用，刷新保留。自定义预览采用 CSP 允许的 data URL，不增加外链或 blob 许可。原数据库与 native 音源没有参与写入。

真实双 PostgreSQL 集成测试覆盖无登录 401、非管理员 403、并发首写仅一个成功、旧版本 409、PNG 方向旋转与去 EXIF/ICC、WebP 的 SHA/ETag/HEAD/304、SVG/伪 MIME/4 MiB 边界、配置字段与外链注入、不同站点及挂载路径隔离、原图切回与显式重置。大 base64 输入先做线性字符、填充与尺寸检查，避免分组正则在合法大字符串上产生栈溢出。

最终 0.9.0-alpha.1 构建的入口脚本实际 HTTP 请求为 `Content-Encoding: br`、`Vary: accept-encoding`；原文件 278,325 字节，传输 81,168 字节，解压 SHA-256 与磁盘文件相同。实际浏览器 worker 为 activated，压缩响应已进入公开缓存；读取缓存响应解码后同为 278,325 字节且 SHA 一致，验证安装校验没有误用压缩 Content-Length。此数字是最终验收构建的入口脚本，不冒称整体网络耗时或容量跑分。

同一隔离站点只安装一条测试词和一对本机预制句音。实际检查释义例句、词条例句、收藏句库与学堂段落朗读，英美 MP3 请求成功、播放器收到 playing 事件；切换不同入口仅一个播放，离开学习模块停止。无音频的其他条目禁用按钮，不调用浏览器临时朗读，也未使用真实麦克风。此联调不代替完整音源包的覆盖率验收。

验收后已退出一次性账户、删除仅属于该随机站点的公开缓存并注销其临时 worker，恢复浏览器默认尺寸、关闭自建标签。精确核对进程命令、数据库及表空间 OID 与所属目录后，已停止自建 5199 服务，删除该随机测试库、外置表空间、测试音频副本及一次性凭据；未知连接终止数为零，native 5198 监听进程不变。

补充审查发现亮色 DIY 壁纸可能削弱底部图标和状态对比，已加独立的底部局部渐变保护，不受管理员全图遮罩控制。纯白、纯黑图片在遮罩 0 的 Chrome 临时样式预览中，390×844、320×568、844×390 均保持可读，无横向或正文溢出；仅修改临时页面 DOM，随后 reload 撤销，不写入数据库。三个入口仍为纯图标，未改变首页四区布局。
