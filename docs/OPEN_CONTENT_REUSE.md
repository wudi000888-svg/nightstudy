## 可复现构建与安装

先确认外置盘真实挂载且可写；原始文件下载到外置盘，源码仓库仅保存小型加工包和证据。

```sh
python3 scripts/exam-books-fetch.py --destination /Volumes/XXX/Codex/assets/nightstudy/exam-books-v1
python3 scripts/exam-books-compile.py \
  --source-dir /Volumes/XXX/Codex/assets/nightstudy/exam-books-v1 \
  --ecdict .local/content/ecdict-bc015ed2e24a7.csv
pnpm exec tsx scripts/exam-books-prepare.ts --site main --dry-run
pnpm exec tsx scripts/exam-books-prepare.ts --site main
```

站点 ID 使用实际配置值，不由前端指定数据库。全新 `CONTENT_PACK=ecdict` 首装在基础词典之后自动执行考试词书包；明确的 `demo` 配置跳过。已有安装可以单独预检并安装，不必重装 77 万词典、重置管理员或清空用户。安装器核对站点绑定、依赖词典 SHA、全部词条与中文焦点释义后，在同一事务内写公开词书成员和目标标签；相同 SHA 重放无重复，来源冲突则整包回滚，不覆盖用户词书、释义编辑、收藏或复习记录。

实际验证结果由本轮交付记录补充；本文件的构建命令不是生产已执行的证明。
