# 每日学习任务

对应已部署的0.5.0-alpha.2。下文说明实现规则，文末区分自动回归、浏览器与真实HTTPS验收。

## 目标与计数

选书后确认每日总词数（1–100）及每组大小（1–20）。每日目标包含新学和复习，按本站同一账户内的canonical word去重；悬停查词、收藏、熟词导入与测验不会增加学习词数。同词当天重学可以产生多条真实评分，但只占一个目标名额。词数达标不等于长期掌握。

复习覆盖本站已学且未暂停的发布词；新学从当前选择的本人可见词书选取。先预留当天到期复习，再把可用额度分配给新词。例如目标50词、到期32词，安排32复习与最多18新词；到期70词时安排50复习、0新词，剩余20词持续显示。具体时间尚未到的短期巩固标明等待时间，不以提前评分替代间隔。

额外复习须明确选择，另行标识；会更新真实FSRS状态，仍按词去重，不伪造新的学习词数。延期只改变任务安排，不能更改真实dueAt或制造成功复习。

## 持久任务

每日计划保存UTC起止、时区、学习日、总目标、词书来源与设置版本；每个计划词唯一，保留首次真实评分、当前任务归属和延期状态。固定学习会话继续保存题目快照、回忆评价及独立拼写状态；旧会话可恢复，不因本轮升级丢失。

跨端创建小组通过幂等commandId和服务端事务分配；同词不同时占用多个主任务，已接受评分保留幂等回执及进度版本。修改目标仅调整未开始的安排，已签发小组继续有效；减少到低于已练或已预约数量时明确显示超额。切书更换新词来源，不清空记忆或已签会话。暂停、恢复、延期和历史列表仅可访问本人任务。

学习日按账户IANA时区凌晨4点划分，DST用实际本地边界计算。改时区在下个学习日生效；已经生成的计划保留边界快照。跨日仍允许完成原小组，实际评分绑定接受时的学习日，结转按同词去重。旧评分保留其原有日历统计，新评分按持久计划归属，原始历史不重写。

## 记忆与统计

采用遗忘与间隔复习原则，继续使用ts-fsrs 5.4.2及版本化保持率参数。FSRS决定已学词何时复习，词书与熟词证据决定新词候选；没有未经验证的个人生理曲线或不背单词内部模型。保持率0.9是调度目标，不是实测准确率保证。

今日任务分别显示已练不同词、复习/新学分配、已预约、未安排逾期、短期巩固和待拼写。尚有必要巩固或待同步时显示真实状态，不能直接标全部完成。拼写不会重复写入记忆评分。

未来7日负担只依据当前due日期计算，明确假设期间不再复习；不是模拟未来新学或保证每天实际数量。真实评分后预测刷新。个人记忆页面继续区分模型预测、自报回忆反馈和客观拼写。

## 词卡与发音

桌面细指针悬停英文词即打开轻量非模态词卡，背景清晰、正文不锁滚动；移入词卡保持，离开词与卡后短延时关闭。点击可固定，Esc/关闭/外点退出，键盘可打开并使用卡内控件。移动端点击打开。0.6卡内正文不递归点词，保留词性、解释与英美读音，来源许可在独立说明页查看；未揭晓的学习答案仍保持遮蔽。

美式、英式各一行，喇叭在对应IPA前；一击播放该口音，切换停止旧音频，再点停止。实际开始、结束、加载和失败状态分别显示。真人、服务器合成与用户主动选择的设备备用分别标注，保留来源及许可；没有可用音源的口音不假报播放成功。
