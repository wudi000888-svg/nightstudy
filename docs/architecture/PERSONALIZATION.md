# 熟词测试与个人记忆方案

本稿仅设计，不包含实现或部署。用户新增需求是熟词导入导出、按学习目标测验、按熟练度安排学习，以及每个人可见的遗忘曲线。核心规则是把“用户自报”“客观测试”“真实复习反馈”分开存储，并据此调整计划，保留每次变化的来源。

墨墨公开介绍了遗忘曲线、学习情况和记忆持久度三类统计视图。本项目借鉴这类可解释的个人记忆展示，调度采用独立的 FSRS 实现，不声称获得墨墨内部模型。[开发者功能介绍](https://apps.apple.com/us/app/id888483369)，[FSRS 公开实现](https://open-spaced-repetition.github.io/ts-fsrs/)。

## 熟词导入与导出

熟词列表表示已有知识证据，不等于收藏列表，也不等于人为创造若干次成功复习。每个条目引用站点内稳定 `study_item`，记录 `source_type`、来源批次、声明时间、确认状态、证据版本和有效性。

第一版支持纯文本一行一词、UTF-8 CSV 和本项目版本化 JSON。正式 CSV 导出列名为 `lemma`，导入可接受 `headword` 作为兼容别名；`language` 缺省时使用本站词库语言，并支持可选 `pos`、`familiarity`、`note`。JSON 可保留稳定 ID、词面、来源、时间和格式版本。跨实例导入不能信任外部 userId/siteId 或假定外部 UUID 有效，必须重新映射。外部文件的 verified/confirmed/真实复习标签只作为来源元数据；普通熟词导入一律生成自报 claim，不升级为本站验证证据，也不生成实测曲线。完整备份另走受控恢复并保留导入来源标记。

导入流程为上传 → 限额/编码/格式检查 → 规范化与去重 → 查词匹配 → 预览 → 用户确认 → 后台批次提交。预览明确显示匹配成功、歧义、重复、未知、冲突和预计影响；遇到不同语言、同形词、短语或多个候选，不悄悄取第一项。词形归一化保留原始输入，不把所有词尾机械截断。

| 情况                   | 默认处理                                     |
| ---------------------- | -------------------------------------------- |
| 同批次重复             | 合并展示；不重复增加熟词数                   |
| 已有同来源熟词         | 幂等更新或跳过，预览说明                     |
| 已有真实学习进度       | 保留 FSRS 和历史，只新增熟词证据             |
| 导入熟词但最近复习忘记 | 不覆盖新证据，降级为待复核                   |
| 词不存在或匹配歧义     | 留在错误/待确认清单，支持下载修正            |
| 撤销某次导入           | 撤销该批次的声明；保留其他来源和后续真实作答 |

单次导入设置字节数、条目数和频率上限，解析与匹配在有界任务中执行，任务中断能续跑，最终效果有批次级一致性。CSV 导出要处理表格公式注入，导入内容按纯数据处理。文件可临时流式处理；无持久文件 provider 时不把导出或原文件留在临时容器目录供另一个副本下载。

用户可以导出全部熟词、当前目标/词书内熟词、已测验确认的熟词或自报熟词。导出包含分类和来源，不能把所有用户混入一个文件；站点/用户身份由当前会话决定。完整版备份与“熟词交换文件”是两种清晰的导出选项。

## 目标水平测试

用户先选目标（雅思、四级、六级、高中、日常），再选择该目标下的已发布词表版本。测试诊断的是这个范围内的词汇熟练度，不输出未经验证的考试总分、英语等级证书或整体能力结论。

初测建议约 30–50 个词、5–10 分钟，属于本稿默认目标，需在真实体验后调整。题目来自已审核题库，按词频/目标层级分层随机抽样，并混入少量导入熟词做抽查。不能只测最前面的简单词，也不能用同一套固定题反复测出虚高熟练度。

题型覆盖释义识别、语境理解和拼写；第一版将认知与产出能力分开报告。音频题可作为后续扩展。选择题用同词性且合理的干扰项，拼写题按版本化 acceptedAnswers 判断，不通过题干提前泄露目标词。跳过、猜测、不认识单独记录；反应时间用于质量提示，不把输入法或辅助功能用户的慢回答直接判为不会。

| 报告内容     | 表达方式                                       |
| ------------ | ---------------------------------------------- |
| 已实测词     | 每词认知/拼写结果、题目版本与时间              |
| 目标范围估计 | 分层表现、样本量与不确定范围，明确未逐词测完   |
| 熟词导入抽查 | 被抽中的自报熟词确认率及需复核项               |
| 计划建议     | 推荐的新词量、复习预算和抽查比例，以及推荐原因 |
| 证据充足度   | 初测/数据不足/已有连续复习记录等状态           |

初测结束后用户可以应用推荐计划，也可保留自己设置。更换目标时重新取该目标范围，不清空全局已测或复习记录；结果始终携带目标与词表版本。目标词库更新后明确标记测试基线版本，不把旧样本自动当作新版全覆盖。

基线抽样记录各层总体词数、纳入概率、样本量与权重。追加的薄弱词辨别题和熟词抽查默认单独报告，不混进全目标外推；若合并估计，则必须按明确的抽样设计加权并验证。无法可靠外推时只报告样本表现，不输出全目标熟悉词量的精确数。

## 熟练度与计划

熟悉度由 `mastery_claims` 和 `assessment_results` 提供先验，真实复习由 `study_progress/review_logs` 提供后验。每条证据有有效性和来源，近期忘记会降低对应词熟练度。未测试词只能按层级推断选词权重，不能批量标为“已经掌握”。

| 分层         | 典型依据                                                      | 计划行为                                                 |
| ------------ | ------------------------------------------------------------- | -------------------------------------------------------- |
| 未知/未测    | 没有可信证据                                                  | 正常进入新词选择与初测                                   |
| 自报熟悉     | 导入或手动声明，未验证                                        | 减少新词曝光，保留较高抽查概率                           |
| 认知熟悉     | 释义/语境通过，拼写较弱                                       | 减少释义重复，增加适量拼写练习                           |
| 测验确认熟词 | 首轮识义加至少一项主动/语境客观验证通过；即时重答不算独立证据 | 可计入已覆盖，降低额外曝光，保留间隔抽查；不等于长期稳固 |
| 长期稳固     | 分散时点的客观确认和/或持续稳定的真实复习表现                 | 明显降低额外曝光，仍保留间隔复习和低频抽查               |
| 不稳定/遗忘  | 最近失败或证据冲突                                            | 回到强化或重学，缩短安排并说明原因                       |

每日计划由四个队列组成：到期复习、薄弱词、新词、熟词抽查。先满足合理的到期负担，再按用户目标分配新词；保留少量抽查预算，让熟词不会永远消失。优先级和抽查参数版本化，初版使用可解释规则，不要求训练一个黑箱模型。

“熟练的词少出现”落实为降低新词/额外强化选择权重，以及在真实证据充分后自然延长复习间隔。不能因为一次导入就把所有 FSRS dueAt 改到数年后。已有调度词优先遵循 FSRS，抽查动作、额外复习与每日新词计数分别记录。用户需要永久隐藏某词时，应显式使用暂停选项，并能恢复。

词书进度显示“学过”和“测验确认熟词”两部分，已覆盖为二者并集；单纯自报导入另列。测验和导入不增加当日新学/复习次数；实际学习与复习继续按接受的动作计数。

## 个人遗忘曲线

每个人看到自己的站点内数据，按全部已学词、当前目标、词书或单词切换范围。图表由三种视图组成：

1. 预测记忆保留率：基于当前 FSRS 状态，展示未来不复习的条件下随时间变化的预测；单词可见下一次到期点。
2. 实际回忆反馈：按距离上次学习的间隔分桶，显示忘记/记住的反馈比例和样本量；图名标明它来自个人复习样本。
3. 记忆持久度与复习压力：稳定度分布、近期遗忘、未来到期词数和预计负担。

预测使用库的 retrievability 接口和持久化参数，不手绘一条所有用户都相同的指数线。生成响应固定 asOf 时间、词集/内容版本、模型参数版本和过滤范围；聚合采用固定词集的均值及分布，不能边计算边改变分母。用户选择“计划复习后的预测”时，必须与“不再复习的预测”分开，不能把模拟安排画成实际效果。[FSRS 预测接口说明](https://open-spaced-repetition.github.io/ts-fsrs/#retrievability)。

第一版的聚合曲线带表示固定词集中各词预测值的分位范围，图例明确写“词间分布”，不是个人准确率置信区间。单词图不画词间分布带。参数不确定性或经过验证的置信区间属于独立的后续视图，不共用这套图例。

实际图可以用时间间隔桶（例如 0–1 天、1–3 天、3–7 天等，最终边界待验收），展示该桶中 `Again` 的比例及其他评价分布。它是自报回忆反馈，和客观拼写正确率分开；抽样方式、复习选择与样本少都会影响代表性。数据较少时显示散点和样本数，不拟合一条看似精确的个人曲线。

| 数据状态     | 页面行为                                                 |
| ------------ | -------------------------------------------------------- |
| 尚未实际学习 | 空态解释需要学习与复习记录；可以展示明确标注的模型说明图 |
| 只有熟词导入 | 展示导入分布与抽查建议，不伪造个人 FSRS 曲线             |
| 少量初学记录 | 显示模型预测与“初始参数估计”，实测图标明不足             |
| 持续复习     | 显示个人预测、实际回忆桶、变化趋势与样本量               |
| 更换模型参数 | 标明版本变化；历史数据按当时参数重建或明确标记重新计算   |

曲线聚合在任务执行器中按用户/范围/状态版本缓存，个人接口做权限校验和私有缓存，不能按每次请求对数万词、数百未来时间点全量扫描。大范围返回固定数量的曲线采样点和分页明细，失效由已接受复习事件触发；延迟更新时显示计算截至时间。

## 新增实体与接口

设计新增 `known_word_imports`、`known_word_claims`、`export_jobs`、`assessment_sessions`、`assessment_items`、`assessment_answers`、`mastery_profiles`、`mastery_evidence`、`plan_versions`、`memory_curve_snapshots`。每个用户对象绑定 siteId/userId，内容题目绑定发布版本，批次和动作有幂等键。

接口组规划为 `/known-words/imports`、`/known-words/exports`、`/assessments`、`/assessments/:id/answers`、`/mastery/plan` 和 `/memory/*`。返回报告时不泄露尚未作答题目的答案；导出任务只能由创建者读取或由有明确权限的审计操作处理。

## 验收条件

- 导入同一文件两次不会重复建词，撤销批次不删除后续学习；外站 ID 或伪造 userId 无法改变他人数据。
- 不同目标的测试覆盖与报告分母正确，猜测/跳过/重复测验不会虚构全词表掌握；每个结果可追溯到题目版本。
- 熟词曝光减少且保留抽查，失败后会重新纳入计划；既有 FSRS 与真实历史不被导入覆盖。
- 同词跨书、测验确认和首学计数去重，导入不虚增签到或复习次数。
- 两个用户的曲线确实来自各自状态；无记录、只导入、少量记录都有正确页面状态。
- 模型预测、实际回忆反馈、客观拼写与参数变化可以区分；曲线缓存键包含站点/用户/范围/版本。
- 并发导入、测验提交和复习不会丢证据，导出大文件与曲线聚合不会阻塞 API 主线程。
