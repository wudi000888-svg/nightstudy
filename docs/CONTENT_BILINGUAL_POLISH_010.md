## 内容制作与保护规则

制作仅使用固定公开语料和 Codex 直接撰写，不调用付费 AI API，不下载或运行翻译模型。现有中文义项的英文对应按该义项完整译写；同词的其他独立英文释义保留，但不冒充当前中文的翻译。发现源义或词性错误时，保留原文，另建有理由和来源证据的学习义项。专业义、否定、动作主体与客体及使用语域需要按原义核对，不能为填满字段而泛化词义。

制作中对另外两个作者分区进行了固定种子、互不重叠的 300 条与 1,000 条语义抽查，偏向长多义、专业术语和介词范围；由 Codex 直接判断，确认的问题进入源绑定审核决定。该抽查覆盖部分条目，不能作为全量语义准确率或专家词典审核结论。

候选句索引绑定冻结的英文原文；沿用公开中译时也绑定原中文，防止索引未变而句文漂移。源身份、未经 trim 的原文字节摘要、制作稿、候选台账和审核决定共同进入制作证据。新增内容保留 `review: pending`；`publishable: true` 表示制作与结构检查允许交付，不是逐条专家认证。

`bilingual-v2` 默认采用严格、单事务安装：源文不符、已有站点自编内容、缺词、新例句身份冲突或更正的来源链不符都会中止并回滚整个包，包括前面已执行的字段补充、纠错义项、词性、默认书焦点和 ContentPack。不会把有冲突的半成品写成 ready；已有 ready 记录若曾计入冲突，也拒绝直接当作成功重复安装。原值冲突应先核实原因，不采用强制覆盖。此默认针对 v2，不能据此描述旧 v1 安装器的历史跳过策略。

既有例句更正使用静态包内的精确锚点：词目 ID、例句 ID、原英文与原中文的 UTF-8 全文字节 SHA-256，以及英中两字段的来源元数据。取得行锁后再次核对，拒绝站点自编内容或来源不明的锚点。只更正中文时，英文及其元数据保持原样；只有显式提供新英文的 3 条才同时替换英文。例句 ID 和顺序不变，原英中全文、完整原元数据、原包 ID、两个原文摘要及更正理由保存在 `translationCorrection` 中。新译来源的原文摘要与 `translatedFrom` 链必须精确对应实际英文，不能仅凭存在一个作者标记就覆盖。

成功安装同一包后的重复执行返回已安装，不重写原值与时间戳；所有表精确不变仍须由最终数据库验收证明。更正公开例句不改动私人词书、用户笔记、历史回答或复习证据。

## 移动端学习精修

保留既有单屏首页四区、雨夜背景和 H5 页面栈，不引入网站式导航或长页首页。

- 长释义先显示可读摘要，点按可展开完整原文；同一义项中英成对排布，其他独立英文释义放在例句之后的折叠区，避免挤掉语境。
- 学习屏默认展开例句，去除重复展示；正文使用一个主要滚动区域，小屏底部学习操作保持可达。长词、音标和英文解释可换行。
- 单词与句音区分读取中、可播放、读取失败和确认缺音；失败可点按重试，不再在懒加载完成前误报“暂无”。普通页面仍只提供美式、英式选项。
- 完整词条已经携带双口音音频与音标时复用现有数据，省去冗余发音查询；句音摘要计算和请求延后到接近可见位置。
- 桌面英文悬停词卡保持清晰背景，卡内文字不递归触发；星标与固定按钮有功能提示，已收藏项可移出生词本。
- 书架按目标筛选并显示结果数，移动端筛选可横向滑动，小屏只保留一个页面标题；触摸设备不保留悬停位移动效，减少动态设置下停用加载旋转。

隔离浏览器已检查 320×568、390×844、844×390 和 1024×768。320 像素宽的长词与音标未产生横向溢出，学习屏底部两个操作完整落在可视区域；完整释义展开、重复例句收敛、独立英文释义、悬停词卡、星标实际入生词本及按钮提示均通过。句音 UK 实际请求返回 206 / audio/mpeg，切换口音转移播放。书架专八/托福筛选，以及选书→每日总量预览→确认→打开实际学习词链路通过。

该验收使用隔离夹具与桌面 Chromium 尺寸模拟，不是最终词库覆盖或实体手机验收。QA 服务、测试库、表空间与临时凭据已清理，临时标签已关闭，未写生产业务数据。

## 书架查询与本机性能对照

书架瓶颈来自统计查询：为筛选已发布词而正向连接大词典，在该数据分布下触发了大范围 Word 扫描。新查询使用现有状态索引找出非 published 词，再排除这些词的书成员；依靠非空状态及 Word 外键，不以词书清单中的静态总数替代实时已发布词数。可见词书仍由同一公开/私有权限条件确定。

本人 learned、covered、known 统计合并到参数化查询，保留 DISTINCT 去重、确认导入、有效自动熟词和用户隔离。没有新增数据库迁移、跨用户缓存或私有进度缓存。真实 PostgreSQL 对照覆盖归档词、其他非 published 状态、未确认导入、撤销的熟词声明、重复声明、其他用户、私有书、已核验交集以及发布状态和成员关系的即时变化。

## 安装入口与复现

下列命令在仓库根目录运行，`default` 应替换为已配置的站点 ID。它们用于说明内容安装入口，不替代既有生产站的专用备份、暂停应用和逐表核验流程。

已有完整 0.9 内容基线时，只安装本次文本增量：

```sh
pnpm bilingual:prepare --pack v2 --site default
```

当前源码中，`bilingual:prepare` 默认选择 `all`；完整 `CONTENT_PACK=ecdict` 的 `db:prepare` 也显式顺序准备 v1、v2。`CONTENT_PACK=demo` 跳过全量内容。已有管理员和用户数据不会因此获准重置；既有站点升级不要以重新执行 seed 代替增量安装。最终空库 Compose CI 结果另列于发布状态。

新站按 [README](../README.md#构建与部署) 准备词典、词组和考试词书基线后，双语内容的独立入口为：

```sh
pnpm bilingual:prepare --pack all --site default
```

Docker Compose 可在同一项目配置中运行内容工具，无需启动初始化服务的默认 seed 命令：

```sh
docker compose run --rm --no-deps --entrypoint pnpm init \
  bilingual:prepare --pack v2 --site default
```

新站需要两包时将上述 `v2` 换为 `all`。每个站点各自安装，站点 ID 必须与数据库 SiteState 一致。

当前制作档案为 `bilingual-v2-authoring.tar.gz`，含公开源投影、候选台账、分区输入与稿件、源绑定审核决定及额外义项/例句输入；不含数据库备份、账户、私人词书、凭据、模型或音频。原创内容层和译写为 MIT，公开语料继续保留各自许可及改编归因。档案大小为 14,276,672 字节，SHA-256：`b8673c3f2cadc60b61d21b7d897d365da47df4ef02de033a40567b01dd108160`。清单见 [v2 来源 manifest](../data/bilingual-v2.sources.manifest.json)；其中的附件 URL 是计划的发行位置，实际公开下载与远端摘要仍待验收。
