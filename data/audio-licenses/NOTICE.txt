The individual model cards must also be retained.

US: en_US-ljspeech-high, trained by Bryce Beattie. Model card specifies en_US
and a public-domain LJ Speech dataset. Original dataset: Keith Ito, recordings
by Linda Johnson/LibriVox. https://keithito.com/LJ-Speech-Dataset/
UK: en_GB-cori-high, trained by Bryce Beattie. Model card specifies en_GB and
about 24 hours of public-domain LibriVox recordings. https://librivox.org/
These are neural synthetic voices, not recordings of a person reading each
NightStudy word. Publisher locale labels are not expert certification of every
word or of a single standard accent. Homographs, stress, names, acronyms and
inflections may be pronounced incorrectly. Original model configs are retained.
Optional phonetic metadata is separately transcribed algorithmically using the
bundled eSpeak-NG en-us or en-gb-x-rp language variant. It is not human-reviewed
dictionary IPA or a transcription certified to match a particular recording.
These variants change only the independent IPA calculation, not the original
Piper model configuration used to render audio. Existing sourced dictionary IPA
should remain authoritative rather than being overwritten by this supplement.

COMMONS REQUESTS AND PROVENANCE
https://www.mediawiki.org/wiki/API:Imageinfo
https://www.mediawiki.org/wiki/API:Etiquette
https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits
https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia
Metadata was checked by a read-only Commons imageinfo batch on 2026-10-14;
original bytes matched Commons SHA-1 and were independently SHA-256 checked.
Accent is based on the specific audio's metadata plus file description, not
inherited from nearby IPA tags, inferred from a filename or relabeled from CA.

The manifest records the generator version, model/config digests, text, accent,
content-addressed output key and each file digest. Public audio contains no user
accounts, private server configuration, credentials or provider tokens.
