## 实现与约束

- `audio-journal.py` 按行流式读取，限制单行大小，跳过截断或损坏的记录；消费者仅保存当前片段需要的文本、口音、模型配置和校音身份。
- 质量核验同样只保存当前选中文件的记录，不整份读取旧质量日志。
- 使用磁盘 SQLite 索引去重，输出新目录，保留旧日志。重复导入相同缓存不使结果膨胀。
- 可直接用有摘要、已完成且大小受限的音频 manifest 建立缓存，避免扫描或复制巨型累计日志。清单提供缓存候选，实际复用仍验证媒体摘要、配置和校音身份。
- 音频进程命中缓存时不加载语音模型。两处生成入口默认一个 worker，顺序处理两种口音；本机按单进程、单模型线程和小批次运行。
- 本机受保护的操作在资源余量不足时拒绝启动；运行中检测任务进程树驻留内存、系统可用比例和新增 swap，超过限额终止本任务进程组。不得为强行完成任务而取消这些保护。
- 不重跑旧 `build-stage-0012-audio.py` 和 `resume-stage-0012-audio-01.py`。原文与摘要先保存在外置 `audio-memory-fix-0001`，原入口现已显式阻止执行。冻结工具链和既有已完成包不覆盖；新修复必须有新工具链和操作收据。
