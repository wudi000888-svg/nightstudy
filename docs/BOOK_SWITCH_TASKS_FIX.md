# 切书与学习任务修复

## 用户确认的规则

2026-10-16 用户确认：切换词书后原未完成任务作废，立即按新书重新安排；已学进度、复习记录和今日已完成词数保留。本轮为 0.11.0-alpha.3 修复，不改学习界面布局、内容包、音频包或数据库结构。

原实现会修改当日计划的词书名称，却保留原书的任务和预约；前端保活缓存与旧链接仍可能恢复旧组。计划的可学习词计数还与实际签发时的内容过滤不一致，导致首页显示有任务但无法取得对应数量。

## 事务与恢复

所有实际选书入口共用同一事务：锁定本人学习设置，结束本人全部进行中或暂停任务，包括延期、额外复习和待拼写组；释放未评分的计划预约，保留已评分词的首次评分时间与当日去重统计。随后重排全站已学词的到期复习与新书新词。不删除 ReviewLog、StudyProgress、任务快照或已接受操作回执。

已结束任务的状态为 cancelled，不能恢复、揭晓、评分、拼写或继续延期。旧任务链接仅展示结束状态。旧版本已经留下的、明确标有另一词书的未完成组，在本人任务读取或操作前结束；没有词书归属的历史全局复习组不猜测来源。仅修改每日目标或自然跨日时继续沿用原有效任务规则。

重复提交已接受命令仍返回成功去重，并携带当前终态。旧选书确认的重试返回当前设置与计划，不能把新选择切回旧书。新建任务核对当前选书和计划版本。切书与评分竞争由相同设置锁串行化：先接受的评分保留，结束后的新评分拒绝。

## 数字与前端

计划、预览、首页与实际签发采用同一可学习义项选择规则，读取最小必要内容，分页跳过不可学习词，不扫描全站词典。新词资格携带词书指定义项；复习来自本人已有进度。

今日已练按真正接受评分的不同词计算；拼写和短期巩固独立显示，不重复增加总目标。每日待安排新词和当前组剩余词是不同数字。新书的已确认设置立即写入缓存，旧首页与任务摘要重新读取后才能操作；账户切换、迟到请求或旧命令回执不能复活旧组。未接受的离线命令保留冲突，允许用户逐条明确处理。

同一 URL 的浏览器后退也会创建新的导航位置。学习请求需核对该位置；开始任务后后退，迟到响应不得再次写回学习任务链接。
