# 真机不背单词观察与夜读英语开发方案

日期：2026-10-16。状态：用户已批准全量施工；`0.12.0-alpha.1` 已完成实现、隔离验证、main / 发行 CI 和公开发布。Native 与 VPS 均已部署并通过原数据保护和公开验收。实施、证据与未验收范围见第 6 节。

本轮精修学习节奏、查词层级、词表浏览和计划设置。夜读已有整屏壁纸、四区首页和模块页面栈，保留这些基础，集中处理阅读层级与操作连续性。参考范围排除广告、积分运营、硬件销售、会员和付费内容。

本次通过系统 iPhone 镜像观察真实应用，核对了首页、Learn 的辨义与揭晓、例句查词、完整词典的免费例句、我的内容、词表、书内搜索、单词本、词库、学习计划和统计。当前参考账号没有待复习词，因此 Review 只确认了完成提示；完整复习评分、拼写、完成一组和再次出现的间隔仍需另行观察。镜像中的键盘输入不能替代实体软键盘验收。

## 2 下一轮页面方案

### 首页继续作为唯一根屏

保留头像、签到、Learn / Review、三个模块图标的关系。Learn 和 Review 各显示一个主要待完成数字，有任务时优先显示继续状态；详细统计、当前词书和任务解释留在“我的学习”。雨夜壁纸继续使用夜读自己的素材与管理员配置，覆盖页展开时暂停背景动画。

三个图标继续对应学堂、我的内容、我的学习。头像进入个人中心，管理入口仍在管理员个人中心内。图标提供可读名称；桌面悬停显示功能名，移动端保持足够触区。

### Learn 和 Review 共用内容组件并保持不同训练目的

建议的 Learn 主链为：

> 进入当前组 → 回忆或可选辨义 → 揭晓当前义项 → 明确记忆评价 → 下一词或巩固 → 完成本组

辨义模式由学习偏好控制。题目只使用与该词义匹配、经检查的选项；数据不足时直接使用回忆与揭晓，不临时拼凑错误释义。选项命中、查词、播放和揭晓都不能直接表示“已记住”。底部“下一词”继续明确表示确认记得并继续，“记错了”安排巩固；需要精细评价时从二级工具选择。

Review 默认保留先回忆后揭晓，避免始终依赖选择题识别答案。完整 Review 的布局与反馈在可用的真实复习样本上再核对，不为了调研向用户账户制造评分或提前到期。

完整词页的首层顺序为词形、英美音标、词性与中英简释、当前义项的一条双语例句。搭配、派生、词根和近义放入统一内容区；有可靠内容才出现对应入口，不保留没有内容的空标签。学习页聚焦当前义项，完整词典提供全部可用义项目录，不将不同意思的例句混在一起。

例句音频与该例句绑定，切义项时同步切换例句与发音对象。词音保留英美各一个入口，喇叭位于对应音标前；缺音时明确不可播放，不出现备用线路、浏览器合成或运行时生成。

### 快速词卡与完整详情分层

移动端点击英文，优先在附近展示简卡，并根据可见空间调整上下位置；空间不足时使用紧凑底部面板。简卡包含词形、词性、简明释义、英美发音、收藏状态和详情入口。背景不模糊，关闭后仍能接着读原句。

“查看详细释义”展开大面板，承载义项目录、双语例句和搭配。面板只有一个主要滚动区域，关闭触区位于安全区内；浏览器后退先关详情，再关简卡，随后才返回页面。直接打开词条链接时提供完整词典页，不依赖必须存在的父页面。

桌面继续使用悬停简卡；星星表示加入或移出生词本，钉子仅表示固定当前词卡，两者都显示功能名与保存反馈。已收藏不再显示“加入生词本”。卡片内不再递归触发新卡，收藏不改变熟练度。

### 词表与查词各自承担清楚的任务

词表默认采用词形浏览，可按行展开词性、简释、英美音标和必要操作；提供统一释义显隐。详细复习次数、预计日期和笔记进入行展开或详情，不让它们占据每一行。

搜索入口明确当前范围。在本书搜索后可以回到词表定位与高亮；全局查词先显示匹配结果，选词后进入词典详情。用户已要求的模糊查找、明确纠错建议和全局排序继续保留，匹配方式与排序收进一个筛选面板，页面只显示当前条件摘要。排序仍在服务端覆盖全体结果，不能只重排当前已加载的一页。

返回列表时保留分类、查询、排序与锚点。锚点使用稳定词项身份；词条不在当前筛选中时给出明确提示，不自动跳到错误位置。

“我的内容”按练习工具、当前学习内容、学习记录和个人积累排列。练习工具优先呈现已完成的可用能力，不加入没有课程或没有数据的空入口。默认生词本、熟词本、句库、笔记和自定义词书沿用现有数据与功能，不再建设另一套收藏系统。

### 我的学习收敛为计划摘要和详情入口

第一张卡放当前词书、可选配套词组、已学进度、每日总目标，以及今日复习和新学的安排；学习统计、日历和记忆曲线作为独立详情进入。移除常驻的算法长解释，保留简短可展开说明。

调整目标使用独立弹层，提供常用数量档位和自定义输入，提交前由服务器预览复习量、新学量和今日剩余额度。预计完成日期须注明是估算，不能把每天的复习负担当作恒定值。更换词书必须在提交前说明旧未完成任务将结束，已学进度与今日已完成词数保留。

本次未观察到参考应用的个人遗忘曲线。夜读已有的记忆曲线继续区分预测、实际回忆反馈与证据不足，不将静态艾宾浩斯示意图伪装成个人实测结果。

## 3 必须保留的业务规则

- 每日目标是新学与复习的总词数，同词当天去重；到期复习先占额度，新词使用剩余额度。
- 实际换书结束所有未完成任务，保留已接受的学习进度、复习记录与当天去重完成词数；旧链接和迟到请求不能复活任务。
- 中断后恢复同一任务的当前词与阶段；未同步操作有明确状态和冲突处理，不静默丢弃。
- 收藏、已学、生词与熟词分别有明确含义；自动移出生词本、加入熟词本由真实复习证据决定。
- 英文可触发词卡，中文不触发，卡片内部不递归。释义和例句保留双语，词义与语境保持绑定。
- 单词优先使用现成可核对录音；缺音及句音仍按已批准的本机离线生成、验证与打包流程处理，线上只播放已发布成品。
- 学习前台不显示代码、许可清单、模型供应商、接口原文或备用链路。后台继续独立承担内容、AI、更新与群站管理。

## 5 后续验收

1. 使用真实 iPhone 和 Android，分别检查浏览器与主屏幕安装态；覆盖小屏、安全区、软键盘展开与收起、返回和音频中断。
2. 对首页、Learn、Review、简卡、完整词典、词表、计划、统计建立同一套状态样本，覆盖加载、空态、失败、继续、完成和待同步。
3. 查词关闭后保持原句位置；列表详情返回保持锚点；搜索与排序切换后不会把旧请求结果插入新条件。
4. 对同词多义、不同词性、词组、缺音和缺内容逐项核对；不能为了模仿布局填入未经审核的例句、派生或词根。
5. 回归切书、重复提交、离线重试、跨日和同 URL 后退等现有任务保护。UI 改造不能改变已确认的每日额度和真实记忆证据。

参考应用完整 Review、下一词与评分的关系、拼写过程、组完成反馈、跨日和跨设备行为，留待具备合适样本时继续观察；不从此次镜像界面反推其后台算法。夜读的业务规则仍以 [H5 应用设计](H5_APP_REDESIGN.md) 与 [切书任务修复](BOOK_SWITCH_TASKS_FIX.md) 为准。

### 内容与功能边界

辨义选择题只从当前首包 **35 词的已审原子义**中取材，且必须具备足够的同词性干扰项才生成；不足时直接使用回忆与揭晓。本轮没有新增词库、逐义审核、例句或音频内容包，仍沿用原有固定包，不能把界面改造扩大表述为全词库逐义完整或选择题全覆盖。既有 35 词首包也不代表这些词的所有意思已穷尽。

每日总目标、当日同词去重、到期复习优先和切书结束旧未完成任务的规则继续保留。真实学习记录、熟练度、收藏和熟词认定仍各有独立含义；动画、点词、选项命中与播放不替代实际回忆证据。
