# 双语释义与例句

0.6 的内容制作采用已有词典语言、公开的真实英中句子对和 Codex 辅助原创补缺，**不使用本地翻译模型**。应用首次安装也不下载或运行翻译模型。此前 OPUS、Qwen 和 TranslateGemma 的小样本候选未获质量批准，不进入本版内容；相关来源证据保留用于追溯，不是运行依赖。

本文件说明本版的内容范围和保护规则。内容编译、数据库安装、HTTP 与生产上线分别验收；数量目标和包的 `ready` 标记不能替代实际数据库覆盖，也不表示全部文字经过专家校对。0.6 最终构建、CI 和生产安装结果以相应版本的验收记录为准。

## 五本词书与独立语言来源

五本内置单词书共有 21,250 个词书条目，去重后为 8,798 个 canonical 词条。完整查词词典仍为 770,611 词；本版内容范围不是全词典的逐义翻译或双语例句覆盖。

ECDICT 的中文 `translation` 与英文 `definition` 分别导入独立 `Sense`。它们没有可靠的逐义对应关系，不能依据行号、词性或相邻位置拼成一对释义。源五书范围原有中文覆盖 8,798 词、英文覆盖 8,729 词；69 个没有英文来源的词采用明确署名的原创英文补充，保留原中文及身份。

本版使用 `definitionPolicy: word-source-languages`：每词实际具有中文解释和英文解释，但两者可以属于不同原始义项。学习卡的焦点 `Sense` 本身有两种语言时才呈现该义项的对照；否则另列同词的英文解释，不冒称它是当前中文释义的精确翻译。实际成对义项和成对词书焦点数量独立报告，不宣称 40,442 个源义项或 21,250 个焦点项全部配对。

同一词跨词书共享记忆身份。安装保留原 `Word.id`、原 `Sense.id`、词书焦点、原非空源文本和用户学习记录。字段补充绑定同词同义项及**未经 trim 的源文本 UTF-8 SHA-256**，只填源文仍匹配的空字段；来源编辑或已有目标内容发生冲突时不强行覆盖。例句独立存入 `WordExample`，表示词级用法，不声明与某一 `focusSense` 完成语义对齐。

## 例句覆盖与归因

本版准备的五书例句范围为 8,786 词：

| 来源                | 词级例句覆盖 | 归因与许可                                                                       |
| ------------------- | -----------: | -------------------------------------------------------------------------------- |
| ManyThings 英中选编 |        4,128 | 原句来自 Tatoeba，保留两端各自句 ID、原句链接、导出署名、原文摘要及 CC-BY-2.0-FR |
| 原创补缺            |        4,658 | NightStudy contributors，Codex-assisted original writing，MIT，待校对            |
| 源词形待核          |           12 | 不编造标准用法，保留源质量警告及空例句                                           |

ManyThings 的固定 `cmn-eng.zip` 导出日期为 **2026-02-13**，实际包含 32,028 对文本，大小 1,386,340 bytes，SHA-256 为 `d606361aa7312dcdfb15ef4fc51cb1e7ed8bc2dc608a7b192626cd36e8403106`。[发布者说明](https://www.manythings.org/anki/)与包内 `_about.txt` 说明其 Tatoeba 来源、署名义务及可能存在的错误。

导出第三列记录的是当次导出所署名的句子所有者，项目使用 `sourceOwnerRole: export-attributed-owner`；它不证明历史最初作者。两种语言各自保留自己的 `sourceSentenceId`、`sourceUrl`、`sourceOwner`、许可和精确文本摘要，中文端关联对应英文句 ID。整对文本标为 `source-export-pair`，不冒充安装当日 Tatoeba API 的直接关系或审核状态验证。中文保留原导出文字，可能含繁体，未声称全部为简体。

匹配要求英文句子出现完整原词形，忽略大小写，不用子串、词形变化或另一个近义词代替目标词。5–18 个英文词是选择短语境的偏好，不能为了句长过滤掉少见词的唯一真实用法。初筛最多保留三个不同英文句 ID 的候选，制作首版时每词取一个；字面匹配和排序不保证适合所有义项。

12 个暂不配例句的词形为 `attent`、`cance`、`eg`、`erm`、`flourishment`、`handtruck`、`n't`、`outskirt`、`pp`、`reservior`、`uptodate`、`vitamine`。词典说明页标记“源词条待校对”，这不是把所有条目断言为拼写错误。后续处理须保留可追溯的源身份，不能为了覆盖数字编造自然用法。[源警告列表](../data/bilingual-source-warnings.json)保留制作输入。

所有本版补充例句仍为 `review: pending`。原创、自校对、社区来源与字符检查都不等于逐条专业审校；已发现的明显错误须修正或排除，不能仅靠“待校对”标签忽略。

## 独立词组书

本版另提供 **437 个常用词组**：四级方向 236 个、六级方向 201 个。它们是独立编选的学习材料，不是官方完整 CET4/CET6 词组大纲，也不是把上游不存在的考试标签当成来源。

词组继续使用站内 canonical 词条。包保留 527 条原中文来源，给其中 501 条补充原创英文。47 条源警告记录中，26 项标记为排除学习，保留原文并另有 13 条明确署名的学习焦点；其余范围复核提醒不等于排除，允许保留已有英文。437 个词组具有可学习的双语焦点和词级双语用法，其中三对真实 Tatoeba 句子分别保留两端关系证据，其余为 Codex 辅助原创。词条搭配链接由实际词组与组成词的精确身份建立，不靠临时模型生成。

词组音频包包含 874 条 US/UK Piper 合成音源，另有两种地区音标；合成来源和算法转写保留标记，不冒充真人录音或专家音标审定。[词组来源清单](../data/phrase-books.source.manifest.json)、[词组包清单](../data/phrase-books.manifest.json)及[音源说明](PHONETICS.md)分别记录内容和媒体。

## 旧会话与学习界面

已签发会话保存原词条快照、焦点、练习题和评价版本。已揭示的词可以只读呈现同一词的新内容：同义项只补兼容的缺字段，新义项与独立词级例句追加显示。源用法指导的少量例外也按精确 Sense ID 和原文摘要绑定，保留数据库原文。呈现操作不改 `questionJson`、原 `focusSenseId`、会话进度、已接受评分或 FSRS 状态。

未揭示的任务仍只返回公开读音与词头，不提前发出释义、例句、来源警告或答案。卡片正文保持词性、解释和实际读音；技术来源、许可、音源类型与待校对依据放在独立词典说明页，便于查看而不干扰回忆流程。

## 制作、安装与验收

公开制作输入不包含账户、私有词书、会话或凭据。`scripts/manythings-source.py` 离线解析固定 ZIP、保留归因并生成候选；`scripts/tatoeba-direct-source.py` 是有界只读 API 采集工具，默认不联网。实际制作通过 `scripts/bilingual-assemble.py` 汇合公开词汇、原句候选与原创稿，再用编译器显式选择 `--definition-policy word-source-languages`。缺稿、重复词、跨词义项、原文摘要或许可不一致必须导致失败。

最终编译产物为精选 `jsonl.gz`、manifest 与校对报告；部署安装这些内容，不需要制作端 Python 模型环境。默认完整内容准备包括源词典、地区 IPA、词组和词级双语补充。`CONTENT_PACK=demo` 是明确的最小测试配置，不能当作完整内容验收。

`scripts/check-audio-install.mjs` 在独立完整安装中检查实际词级两种语言、词书焦点身份、原非空文本摘要、manifest 声明与实际例句数量、源质量例外和词组音源。生产升级另以只读数据库指纹验证既有业务数据；`ready` 只能说明安装状态，不能证明覆盖、词义或媒体质量。

自定义词书可能包含五书包之外的词。不能因为主包安装成功就宣称这些词已经有双语解释或例句。管理员可选的 DeepSeek 仅主动测试和预览候选，不自动入库；其凭据、费用与真实请求边界见 [AI 配置](AI_CONFIGURATION.md)。

应用代码与原创内容使用 MIT；第三方词典、例句、IPA 和音频各自保留许可。完整来源证据见 [bilingual-source.manifest.json](../data/bilingual-source.manifest.json)、[第三方通知](../THIRD_PARTY_NOTICES.md)、[内容包](CONTENT.md)和[音标与发音](PHONETICS.md)。
